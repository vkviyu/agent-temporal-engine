# R27：格式目录与路由检查防漂移

日期：2026-11-17。本项修正当前格式目录及其可执行检查，不修改持久字节布局、
decoder、发布流程或 Snapshot API。没有提交 Git。

## 实际问题和改动

`TestRegistryCoversActualProtocolDispatchMethods` 原来只解析 `session.go` 与
`nodes.go`，并绑定变量名 `req`。服务路由已经拆到 `session_dispatch_core.go`
和 `session_dispatch_view.go`；依靠顶层重复方法名恰好通过不能保证后续新增或移动不漏检。

现在通过 `fs.ReadDir` 发现 service 包全部非测试 Go 源文件，包含平台文件。
检查静态 `.Method` switch 和相等/不等比较，包含 hello，不绑定请求变量名。
registry 与实际方法集合双向比较，非字面量 route 明确报错。
`fstest.MapFS` 负控验证跨文件移动、请求变量改名、未登记新方法、删除已声明方法、
忽略测试 fixture 和拒绝动态 case。它不证明路由可达性；未来改为动态表或其他
分派表示时，必须同步更新检查器，不把当前 AST 约定包装成通用静态分析。

当前 registry 还把已经删除的 `agent.snapshot` 1/2 宣告为可 decode/replay/write。
实际 Agent 只持久化 record root 和 `ATE-AGENT-RECORD\0` records，因此替换为
`agent.record-state` v1，检查 `agentprofile.RecordStateVersion` 和 domain，
并验证旧 family 在三种用途下均返回 Unsupported。公开 `agentprofile.Snapshot`
及其校验/恢复 DTO helper 保留；没有添加旧 reader、迁移或重写路径。

同步更新：

- `docs/formats/registry-and-migration-policy.md`：当前格式和路由检查规则。
- `docs/formats/agent-record-state-v1.md`：当前 registry family 与 schema constant。
- `docs/ATE_REFACTOR_MASTER_PLAN.md`：唯一任务台账。

README 两种语言已指向主计划；旧 refactor baseline 和 M6 状态页已标明历史属性，
保留历史正文与当时的测量结果。R11/R12 报告另外明确旧全量验证和新定向补测的区别，
没有把旧 fingerprint 用来证明新源码。registry 本身是 go:embed 输入，修改会改变
`ate-source-v2` 指纹；最终验证必须对应更新后的源码。联合验证还发现新增
`observation` 包未进入指纹白名单，已补齐并增加当前 `go list ./...` 的包目录对照，
使后续新增 package 未同步指纹范围时测试失败。对应内容变化回归已通过。
