# R26：测试就绪等待与 skip 策略

`TestLocalServiceClientConformance` 在 `Listen` 建立 listener 后直接使用 3 秒
timeout context 执行 Dial/hello，删除 Serve goroutine 后的 10ms sleep。
pin-hold benchmark 的模拟 sleep 保留。

runner 为 skip 增加 `classification` / `policy_id`，按 mode、完整 package、
完整 test/subtest、稳定原因和环境条件匹配静态窄 allowlist。Linux ext4
full-disk/reboot opt-in、模型 opt-in、指定 native 平台及 Unix socket 权限拒绝
分别设定条件；允许的环境 skip 仍标为未验证。未知、无理由、条件不符的 skip
使步骤与总状态 `failed`，入口非零。其他包未列出的平台 skip 同样不自动豁免。

父子测试独立判定，重复运行清除原因状态；无测试包分类为 `no_test_files`，
未选择 lane 分类为 `not_selected`，均不计入真实测试 skip。
原因原文仅保留在私有日志；manifest 保留固定说明、分类、策略 ID 和输出 SHA-256。
已核对当前全部 skip 调用及原因，四处无理由 native skip 保持拒绝策略。

验证环境：Go 1.27.0，Darwin/arm64。

| 检查                                   | 结果                |
| -------------------------------------- | ------------------- |
| runner 普通测试，`-count=1`            | 通过                |
| runner race，`-count=1`                | 通过                |
| runner `go vet`                        | 通过                |
| service 指定用例，普通 `-count=20`     | 通过                |
| service 指定用例，`-race -count=20 -v` | 20 次 PASS，无 skip |

runner 自测覆盖 allowlist 边界、未知/空理由/SkipNow、父子 subtest、benchmark、
无测试包、lane 区分及原因隐私。CLI 子进程在临时小 module 中确认其他检查通过、
`go test` 包级 PASS 后，未知 skip 仍令入口退出 1、manifest 为 `failed`。

本项定向批次未运行产品统一全库；后续 full/race 结果见
[联合验证批次](REFACTOR_R11_R13_R26_R27_2026-11-17.md)。
没有单独补跑完整 native/benchmark lane、Linux ext4 full-disk、跨启动 reboot、
设备掉电及真实模型评估；平台和 opt-in 策略的夹具测试不代表这些外部环境已验证。
