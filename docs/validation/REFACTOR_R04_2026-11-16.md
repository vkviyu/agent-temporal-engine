# R04：Knowledge 单格式验证报告

日期：2026-11-16。结论：R04 完成；阶段 B 其他事项仍按[主计划](../ATE_REFACTOR_MASTER_PLAN.md)推进。

## 最终行为

Knowledge 当前写入、历史读取、import 和 semantic replay 统一使用 v2 indexed records。`knowledge.Snapshot` 保留为公开读取 DTO 和领域选择输入，`Validate`、`Clone`、Frontier、Revision、ContextPacket selection 均保留。

删除旧 owner snapshot 的 EncodeSnapshot/DecodeSnapshot、整快照 ApplyCommand/applyImport reducer、命令版本切换、legacy index/fallback、混合快照拼接和旧 duplicate marker。旧 packet replay 专用的 policy 校验分支及其参数一并删除；当前提交和恢复使用同一规则。重复 indexed record 保留现有 radix root 和 typed write/receipt 语义。

只接受 Knowledge command schema 2。旧命令返回 `knowledge.ErrUnsupportedSchema`，拒绝不生成 receipt、不推进 publication。旧 owner key 仅保留存在性检测；v1-only 或 v1+v2 mixed root 均返回 unsupported，不解码旧值，不返回伪装成空状态的结果。

Recovery checkpoint certification epoch 从 1 升到 2，并加入 `recovery.checkpoint` 格式登记。旧 checkpoint 先验证 authority binding，再返回 unsupported，恢复可回退 genesis full replay；若 journal 包含 v1 Knowledge command，恢复明确失败，不暴露部分 Engine。checkpoint 仍为通用认证投影，不保存 Knowledge snapshot。

没有运行时迁移。包含旧 Knowledge 历史的开发数据需重建；本次未删除本地数据、未提交 Git。Memory 和 Annotation 的快照持久化不属于本次改造。

## 回归证据

- `knowledge/*_test.go`：DTO 不变量、深拷贝、canonical record/command roundtrip、import provenance、packet selection 和旧/未知 command version 拒绝。
- `engine/knowledge_index_integration_test.go`：累计至少 9 MiB 的合法 packets；历史 cuts、逻辑 Revision/Frontier、重复请求 receipt 在 reopen 和 AuditFull compaction 后保持一致；拒绝 v1 后仍可用相同 request key 和 sequence 提交 v2。
- `engine/knowledge_format_rejection_test.go`：v1-only/mixed retained roots 拒绝；空 root 和 v2 root 正常读取；owner 隔离；取消/IO 错误传播；物理合法但 command version 为 1 的 journal 在 semantic replay/open 时拒绝，拒绝前状态、receipt、对象索引不被部分安装。
- `engine/checkpoint_codec_test.go`、`checkpoint_corruption_test.go`：schema 1 拒绝前保持 authority 校验；fallback 从 genesis 重放，不跳过事务；schema 常量与 registry 对照。
- acceptance fixture 改为 canonical observation records roundtrip；benchmark 改为 canonical record 批量编解码，不保留旧 snapshot codec。

旧状态测试使用保留的不可变 roots，不是归档旧版本程序生成的数据库。journal 回归仅变更命令 envelope version，复用当前记录构造器；没有重新实现旧 codec。
