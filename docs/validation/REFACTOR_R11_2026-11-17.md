# ATE R11：领域与跨域独立 oracle

验证日期：2026-11-17。R11 在首版之后补强了模型驱动断言、恢复路径与负控证据。
本轮选择四个跨域缺口，使用固定且可缩减的操作序列；没有重复已有
AgentProfile、Graph、Receipt 和 TaskTrace overview 的强覆盖。

## 新增 oracle

| 范围                         | 测试                                                                 | 独立模型与核心断言                                                                                                                                                                                                                |
| ---------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 五根 RootSet 组合            | `TestIndependentRootSetCompositionAcrossDomainsAndRecovery`          | 只按逻辑 slot 记录 publication fence、业务 root version 和 receipt；Domain、Knowledge、Branch、Control、Receipt 的变化集合与公开 snapshot 对照，拒绝和 retry 不改变投影，reopen、checkpoint、full replay、compaction 保持逻辑结果 |
| Knowledge import/history cut | `TestIndependentKnowledgeImportRetainsSelectedHistoryAcrossRecovery` | 以逻辑 source fact、selected fence、target sequence 建模；只导入 cut 之前的 source fact，source/target 隔离，future source 被拒绝，provenance 和 retry 在 checkpoint、full replay、compaction 后保持                              |
| Memory dependency withdrawal | `TestIndependentMemoryDependencyClosureAcrossDisclosureAndRecovery`  | `Allowed` 直接驱动 snapshot、历史 path node 和新 BuildPath 的比较；path 仅经 Memory 间接依赖被撤回 primary source，use-ban 保留 audit 但拒绝 reuse，privacy 同时拒绝 audit/reuse                                                  |
| Transfer 跨域 disclosure     | `TestIndependentTransferDisclosurePreservesSourceTargetBoundaries`   | `CanReadArchive` 驱动 source/target × owner/foreign 四种查询；非空 mappings、included/gap 和 export block 均有实际对照；source withdrawal 不重写 destination archive                                                              |

模型没有调用生产 reducer、replay、policy closure、ObjectID hash 或内部
`prepare*` 函数。生产对象只用于提交请求和读取公开投影，逻辑期望由测试内
的 map、slice 和状态机维护。

## 验证边界

本轮没有新增 Graph fork/join、Receipt、AgentProfile lifecycle 或 TaskTrace
overview 测试，因为这些范围已经有独立 reference model 和差分回归。也没有
把四种 Memory retraction 或所有 transport 重新排列；policy 四类撤回由已有
reference policy 覆盖，跨 transport 属于 R12。

既有 `TestDurableStateIndependentMapOracleAcrossReopens` 保留固定种子
`1942703` 的 30 批操作及 reopen/receipt 对照。本次四组新增场景使用可手工缩减的
确定性序列，集中验证历史 cut、跨域依赖和权限；不声称包含自动 shrinker 或新的
随机领域生成器。新领域随机生成器明确延期，触发条件是出现依赖操作排列才能复现、
现有固定序列无法覆盖的缺陷；届时固定复现种子并保留缩减后的回归。

首版复核发现 RootSet 模型版本未参与 slot 判断、恢复只比较 fence，以及
Memory 只有直接撤回路径等缺口。补强后 RootSet 用模型版本增量检查真实五根变化，
重复 CreateTask 真实拒绝，恢复比较五根 ID、RootSet、fence 和旧 receipt；
Knowledge future-source 同时进入模型和 API，恢复检查也重复核对 import receipt。
这些 root ID 比较证明投影稳定，不是独立重新计算生产 hash。

Memory/Transfer 在撤回前创建 checkpoint、撤回后保留 suffix，随后分别验证
checkpoint 命中、禁用 checkpoint 的 full replay、AuditFull compaction 后的
checkpoint 和 full replay。每阶段重跑实际 disclosure/reuse/export/owner 断言，
检查恢复计数；没有新增撤回后重新认证 checkpoint 或物理隐私擦除的承诺。

四组均通过实际差分比较器接收故意错误结果：无关 root slot 变化、cut 后 fact
混入、错误允许 reuse/private disclosure、archive 越权/空 mapping/撤回后 export。
这是比较器负控，不是修改生产实现的 mutation testing，也不证明所有可能缺陷均可检出。
