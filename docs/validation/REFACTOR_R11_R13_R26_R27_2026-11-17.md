## 各项证据与限制

- [R11](REFACTOR_R11_2026-11-17.md)：模型驱动比较、实际拒绝、恢复形态和错误结果负控；
  固定种子基线保留，新领域随机生成器按明确触发条件延期。
- [R12](REFACTOR_R12_2026-11-17.md)：代表场景矩阵、真实丢 ACK 重试、预算拒绝和
  Unix 子测试无 skip 的定向证据；不承诺所有 API × transport 全排列。
- [R13](REFACTOR_R13_2026-11-17.md)：非阻塞队列、实际阶段/恢复/读取/cache/pin 观测，
  定向 race 和开销样本；cache 记账不等于全引擎常驻内存。
- [R26](REFACTOR_R26_2026-11-17.md)：未知 skip 使 CLI 失败的子进程回归，
  Unix 就绪测试普通/race 各 20 次；环境允许 skip 仍为未验证。
- [R27](REFACTOR_R27_2026-11-17.md)：全 service 路由盘点、移动/新增负控、
  当前 record-state family 和已删除 snapshot family 拒绝。

真实模型、Linux ext4 满盘/跨启动重启与设备掉电仍需要独立环境。
本批全库普通/race 和本机 Unix 执行不能替代这些证据，也不表示 R14–R25 已完成。
