## 明确保留的缺口

- Summary 的有版本派生契约、生成活动/原始输入/输出/复核谱系及多轮摘要效果。
- Query 尚未创建 Task 时的 durable intake；结果/消息消费、知识与下一动作的跨根原子提交；子代理 seed/Continuation 原子归属。
- 独立出站 grant/revoke 和执行器发送的串行化。当前 candidate/输出返回前 policy 检查不能证明网络发送与撤回无 TOCTOU。
- 当前访问检查只认识显式记录的来源关系，不能检测任意无来源字节复制；generic diagnostics/低层原始存储、旧异常 provenance 和外部已发送字节也不由此获得隐私删除保证。
- typed Validation 与精确目标、产物、命令、环境的绑定；完整独立 oracle、Event 归因和所需上下文分区。
- 跨 Space 脱敏迁移、真实模型对照和大规模开销验证；现有 benchmark 是测量时实现的开发基线，后续安全 gate 的开销需要在性能阶段重新计量。
- 格式冻结/显式迁移与完整平台耐久矩阵。`docs/PLATFORM_SUPPORT.md` 区分 Darwin 原生验证与 Linux 仅交叉编译。
