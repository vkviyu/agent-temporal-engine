## 实际 CLI 往返

通过 `go run ./cmd/ate` 在独立临时目录执行：

1. `init-journal DIR`：创建 LSN0、96 字节 genesis prefix，verified=true、synced=true、semantic=false。
2. `recover-journal DIR`：同一 Store/CommitDigest，LSN0 不变。
3. 手工追加并同步 22 字节未发布内容后，默认 recover 返回 exit1、tail=22、preserved、synced=false；文件保持原样。
4. `recover-journal --quarantine-tail DIR`：exit0、tail=22、quarantined；检查原始证据逐字相同，原 CommitDigest 不变。
5. 再次 recover：exit0、tail=0、LSN0、verified/synced=true，semantic_replay_verified 仍为 false。

真实业务域对象存在性、RootSet/StateOps replay、持久 command receipts 和权限尚未验收；它们是 M1c 及后续阶段的工作，见 [当前状态](../M1B_STATUS.md)。
