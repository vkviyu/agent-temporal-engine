# M2a 验收记录

M2a 是 Revision/Branch 图算法的独立公开包纵切面。它尚未把 graph 写入 ATE Journal，因此不宣称持久图和 Agent profile 已完成。

- `go test -race ./graph -count=1` 通过。
- graph tests 覆盖确定性 RevisionID、完整 parent、Fork O(1) 与 CAS、绝对 key Diff、删除/新增/更新、三路 Join 冲突、显式 Resolve、歧义 merge base 拒绝，以及 Revision/Branch canonical codec 的重编码/摘要校验。
- 架构依赖测试通过：`graph` 只依赖公开 `codec`/`model`，没有 `internal` 或第三方依赖。
- graph 接入后的最终 `go test -race -count=1 ./...`、`go vet ./...`、`go build ./...` 均通过，`gofmt -l .` 无输出。

下一步是把 Revision/Branch 规范对象登记为强引用 schema，接入持久事务/replay，再为 Fork/Join 提供 API 与服务协议。`graph.Store` 的内存容器不构成持久权威。
