# ATE R10：复合事务 publication/recovery 故障矩阵

本轮完成 R10 的选择性矩阵和此前缺失的跨层回归。目标是确认复合事务在
故障后只能恢复为 durable ACK 对应的完整旧状态或完整新状态，避免把底层 fault
点机械地扩展成所有领域的全排列。

## 矩阵

| 复合场景                                                               | 故障位置                                                    | 当前证据                                                                                                        | 预期 oracle                                                                            |
| ---------------------------------------------------------------------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Work message consume + Knowledge observation + Continuation checkpoint | CURRENT replacement 前/后                                   | `TestWorkMessageConsumptionRecoversWholePublicationAfterCurrentFault`                                           | LiveControl、ExecutionKnowledge、Continuation 和 receipt 同属旧或新 publication        |
| Work child spawn + child authority + Knowledge seed + Continuation     | CURRENT replacement 前/后                                   | `TestWorkChildSeedPublicationUnknownNeverRecoversPartialFacts`                                                  | child execution、authority、seed observations、continuation 同步出现或同步缺失         |
| Work child authority + parent accepted result                          | CURRENT replacement 前/后                                   | `TestWorkChildAuthorityAndAcceptedResultRecoverAsOnePublication`                                                | child authority/seed/continuation 与 parent Activity acceptance 同属旧或新 publication |
| Work message consume + Knowledge at partial segment write              | segment append partial write                                | `TestWorkMessageConsumptionPartialSegmentWriteRecoversWholePublication`                                         | partial tail quarantine 后只保留旧 Knowledge cut；重试产生完整新 publication           |
| Query decision + accepted model result + continuation                  | CURRENT replacement 前/后                                   | `TestQueryDecisionAcceptancePublicationUnknownRecoversWholeTurn`                                                | accepted result、Query decision、next continuation 和 receipt 同属旧或新 turn          |
| Agent profile publication                                              | CURRENT replacement 前/后                                   | `TestAgentPublicationUnknownNeverInstallsCandidate`                                                             | unknown 不泄露 candidate proof；reopen 只选择已认证旧/新 prefix                        |
| Agent + Domain mixed group                                             | 同一 publication group 的 CURRENT fault                     | `TestAgentAndDomainCandidatesUseOneGroupPublication` 及相关 rejection tests                                     | Domain、Agent、CommandReceipts 的 root membership 和各自 receipt 保持                  |
| Knowledge packet + ExecutionKnowledge                                  | CURRENT replacement 前/后                                   | `TestKnowledgePublicationUnknownDoesNotInstallPrivateCandidate`                                                 | packet、knowledge root、receipt 不出现半组状态                                         |
| Graph Join 的 DomainStates + BranchRefs                                | CURRENT replacement 前/后                                   | `TestGraphJoinUnknownPublicationKeepsDomainAndBranchAtomic`                                                     | branch head/version、domain value、receipt 同属旧或新 Join                             |
| Graph Join 在 AuditFull compaction 后                                  | compaction 后 CURRENT replacement 前/后                     | `TestGraphJoinUnknownPublicationKeepsDomainAndBranchAtomic/compacted=*`                                         | 退休布局和 checkpoint/manifest 变化不改变 Join 的 old-or-new 选择                      |
| 五根 checkpoint、suffix replay、AuditFull compaction                   | checkpoint/reopen/compaction                                | `TestCheckpointFiveRootsHistorySuffixAndCompaction`、`TestCheckpointRecordStateThenSuffixWorkMatchesFullReplay` | 五根、历史读取、receipt、checkpoint suffix 与 full replay 一致                         |
| storage publication cleanup                                            | candidate、intent、retired source、FILE/OWNER close failure | R07/R08 publication maintenance、TailReject 和 recovery fault suites                                            | cleanup 失败保留 ownership；重试后才能释放；不删除 CURRENT 证明闭包                    |

Graph Join 的 compaction bridge 是本轮新增回归，覆盖四个组合：
`compacted={false,true} × after-current={false,true}`。测试通过后，普通 Join
publication 和 compaction 后 Join 的 root atomicity 具有相同 oracle。

Query decision acceptance bridge 也覆盖两个组合：
`after-current={false,true}`。它验证 accepted model result、Query decision、
下一步 continuation 和 receipt 不会跨 publication 混合。

## 选择性边界

本轮没有把每个复合场景与 segment write、file sync、manifest install、CURRENT
sync、directory sync 的所有排列相乘。storage 层已经对这些物理故障和 cleanup
ownership 有独立 fault matrix；Engine 层的关键证明点是 candidate 是否进入
authoritative CURRENT，以及 semantic replay/reopen 是否选择完整 prefix。重复
覆盖每个底层调用不会增加新的语义 oracle。

本轮没有留下新的 R10 组合缺口。后续只有在发现新的语义 oracle
或新的 fault source 时才需要追加覆盖，不能因为底层故障点数量多就自动扩展矩阵。

矩阵中的 durable ACK、unknown、fenced 和 cleanup 预期均已有对应 oracle，避免
把“底层调用返回错误”误写成上层可以判断的结果。R10 已完成；后续只在出现
新的语义 oracle 或 fault source 时追加代表场景。
