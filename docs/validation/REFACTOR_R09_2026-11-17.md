## 交付内容

`scripts/verify` 提供以下模式：

- `quick`：改动 Go 文件格式、diff、vet、build；
- `full`：quick 加全库普通测试；
- `race`：quick 加全库 race；
- `benchmark`：quick 加固定一次迭代的 native benchmark；
- `native`：quick 加 storage native publication、crash/reopen 和 recovery；
- `fingerprint`：只生成源码指纹。

每次运行都在仓库外创建唯一报告目录，写入 `started.json`、最终
`manifest.json` 和各步骤私有日志。manifest 记录 R 编号、模式、Go/OS/arch、
HEAD、dirty 标志、起止源码指纹、逐命令退出码、skip 原因和未选择 lane。

benchmark 使用 `go test -json`。因此 benchmark 内部的 `b.Skip` 与普通测试 skip
一样会进入 manifest，不会因为 benchmark 命令本身退出 0 而被误记为已验证。
